# NameSpark

NameSpark is a simple local name generator MVP built with Next.js, TypeScript, and Tailwind CSS.

Users can add keywords, generate creative brand-style name ideas, and see the results as clean neon-green bubbles. The generator is fully local and does not use an AI API, backend, or database.

## Features

- Add and remove keyword chips
- Generate 12 local name ideas
- Randomized brand-style results on each Generate click
- Responsive single-page layout
- Black and neon green visual theme
- No backend, database, or external API

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the app:

```bash
http://localhost:3000
```

Build for production:

```bash
npm run build
```

## Project Goal

This MVP is intentionally small and focused: type keywords, add them to a list, generate names, and review the results.
